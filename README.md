# 🧠 NLP Project – Natural Language Processing

---

## 📌 Project Overview

This project focuses on **Natural Language Processing (NLP)** and covers the complete workflow of working with text data, from data loading and exploratory data analysis to preprocessing, vectorization, machine learning, deep learning, and Transformer-based models.

The project also includes a separate **Disaster Tweets Classification** task using NLP techniques and a **GloVe + LSTM** model.

---

## 1. Loading Data 💎

* Load the NLP dataset.
* Inspect the dataset.
* Display the first few records.
* Check dataset shape.

* Check for missing values and duplicates.

# 3. Data Preprocessing ⚙️

## 3.1 Cleaning the Corpus 🛠️

Clean the text data using appropriate NLP preprocessing techniques:

* Convert text to lowercase
* Remove punctuation
* Remove special characters
* Remove URLs
* Remove unnecessary spaces
* Remove unwanted symbols
* Remove stopwords where applicable

---

## 3.2 Stemming 🛠️

Apply stemming to reduce words to their root form.

Example:

```text
playing → play
played  → play
plays   → play
```

---

## 3.3 All Together 🛠️

Combine the preprocessing steps into a complete NLP pipeline:

```text
Raw Text
   ↓
Lowercase
   ↓
Remove URLs & Special Characters
   ↓
Remove Stopwords
   ↓
Tokenization
   ↓
Stemming
   ↓
Clean Text
```

---

## 3.4 Target Encoding 🛠️

Convert target labels into numerical values suitable for machine learning models.

Example:

```text
Positive → 1
Negative → 0
```

# 5. Vectorization 🔢

Convert text into numerical representations that can be used by machine learning and deep learning models.

## 5.1 Tuning CountVectorizer

Use `CountVectorizer` to create a **Document-Term Matrix (DTM)**.

Tune parameters such as:

* `max_features`
* `min_df`
* `max_df`
* `ngram_range`
* `binary`

---

## 5.2 TF-IDF

Implement **TF-IDF (Term Frequency–Inverse Document Frequency)** vectorization.

TF-IDF assigns importance to words based on their frequency within documents and across the complete corpus.

---

## 5.3 Word Embeddings: GloVe 🧠

Use **GloVe (Global Vectors for Word Representation)** to represent words as dense numerical vectors.

GloVe embeddings are used for deep learning-based NLP models.

---

The models can be evaluated and compared using:
